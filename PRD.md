# PRD — KNJ LAB

Версия 0.1 · Этап 0 · Источник: концепция KNJ LAB (презентация, аудиторское заключение, мастер-промт v2, мастер-промт владельца).

## 1. Видение
KNJ LAB — **самостоятельная цифровая практика**, а не онлайн-школа. Ученик не просто читает теорию, а экспериментирует (лаборатории), решает задачи разного уровня, проходит тесты и видит свой прогресс. Родитель видит понятный результат и пробелы ребёнка.

Ключевое обещание: *не просто показать правильный ответ, а помочь понять ход решения и научиться применять знания.*

Юридическое позиционирование (из аудита): «цифровая образовательная платформа с доступом к электронному контенту и интерактивным инструментам по подписке». Не обещаем аттестатов, официальной аттестации, статуса школы.

## 2. Аудитория и роли
| Роль | Кто | Главная ценность |
|---|---|---|
| Ученик | 7–11 класс, часто со смартфона | понятные объяснения, практика, лаборатории, прогресс |
| Родитель | платит, контролирует | объективная статистика, пробелы, регулярность, отчёты |
| Контент-менеджер | автор материалов | удобный редактор тем, задач, формул, медиа |
| Методист (reviewer) | предметный эксперт | проверка и публикация, контроль качества и переводов |
| Администратор | владелец/оператор | пользователи, КТП, тарифы, платежи, аналитика |
| Поддержка (позже) | оператор | статус оплат и доступа без доступа к учебным данным |

Права проверяются на сервере и в БД (RLS). Подробно — [SECURITY.md](SECURITY.md), [DATABASE.md](DATABASE.md).

## 3. Решения владельца и разрешённые противоречия
| Вопрос | Решение |

| Языки | RU + KK с первого дня; архитектура на N локалей; EN — этап 9 |
| Хостинг ПДн | БД и серверная логика — в облаке РК (self-hosted Supabase) |

## 4. Функциональные модули

### 4.1 Главная (публичная)
Логотип, навигация, переключатель RU/KK, вход/регистрация, возможности, предметы, лаборатории (живое демо), преимущества, тарифы (из БД), FAQ, контакты, ссылки на юридические документы.

### 4.2 Кабинет ученика
Приветствие; мой класс; мои предметы; «продолжить обучение» (последняя тема/тренажёр); прогресс по предметам; последние результаты; рекомендованные темы (по слабым местам); достижения; количество решённых задач; активность 7/30 дней.

### 4.3 Учебный раздел
Иерархия: **Класс → Предмет → Четверть → Раздел → Тема → Теория → Формулы → Практика → Тест → Результат.**
- Распределение тем по четвертям **не выдумывается**: хранится как редактируемая «учебная программа» (`curricula`) с версией, учебным годом и типом школы. Одна тема может входить в несколько программ.
- Сценарий темы (8 шагов): цель и простое объяснение → формулы, обозначения, единицы, иллюстрация → разобранный пример → типичная ошибка → практические задания → подсказка и проверка → пошаговое решение → следующая тема.

### 4.4 Теоретический материал
Название, краткое описание, цели обучения, теория (Markdown + LaTeX), формулы, обозначения, единицы, примеры, иллюстрации, пошаговые решения, типичные ошибки, практические задания. Рендер — KaTeX.

### 4.5 Сложность и тренажёр
- Уровни: **лёгкий** (бесплатно), **средний**, **достаточный**, **сложный** (по подписке).
- Тренажёр по теме на **100 задач** (генерация из шаблонов, перемешивание, повтор ошибок).
- Сохраняется: попытки, верные/неверные, время на задачу, история, % верных, динамика.
- Достижение «Первые 100 задач» — по факту. **Освоение темы** определяется не количеством, а: точность ≥ 80 % на ≥ 2 уровнях (из них хотя бы один платный, если доступен) за последние 30 задач + сданный тест темы ≥ 70 %. Пороги настраиваются.

### 4.6 Геометрическая лаборатория
Планиметрия и стереометрия: точки, отрезки, прямые, углы, окружности, многоугольники; куб, призма, пирамида, цилиндр, конус, шар; сечения плоскостью. Параметры задаёт ученик (сторона, высота, радиус, угол, число вершин, положение секущей). Масштаб, вращение, перемещение, размеры, вспомогательные линии, расчёт площадей/объёмов. Вычисления — в `packages/geometry`, покрыты тестами.

### 4.7 Физическая лаборатория
Разделы: механика, МКТ и термодинамика, электричество, магнетизм, оптика, колебания и волны (полный перечень — в мастер-промте, раздел 6). Каждая лаборатория: параметры → пересчёт → визуализация → график → показания приборов → вопросы по результату. Упрощения модели показываются явно.
**MVP:** равномерное движение `S = vt` (эталон), закон Ома и цепи (последовательное/параллельное), тонкая линза. Далее по одной лаборатории за итерацию.

### 4.8 Справочник
Формулы, таблицы, физические константы, геометрические и алгебраические формулы, единицы и СИ, обозначения. Поиск (RU/KK + LaTeX-имя), фильтры по предмету и классу, избранное, быстрый доступ из темы. Бесплатен.

### 4.9 Тестирование
Типы: один ответ; несколько ответов; число (с единицами и допуском); формула (проверка эквивалентности); пропущенное слово; пропущенная формула; сопоставление; последовательность; геометрическая задача (числовой ответ/интерактив); физический расчёт.
Формирование: по теме / разделу / четверти / классу / предмету. Режимы: тренировочный (без таймера, с подсказками) и экзаменационный (таймер, разбор после).
Результат: балл, число верных, ошибки, верные ответы, объяснения, рекомендации.
Free-тариф: тесты только по лёгкому уровню, не более 3 в день (настраивается).

### 4.10 Геймификация
XP, уровни, серии (дни подряд), медали, прогресс по предметам. Примеры: 10/100/500 задач, 7/30 дней подряд, освоенная тема, идеальный тест, мастер алгебры/геометрии/физики (= освоено ≥ 80 % тем предмета в классе). Награды за **подтверждённое освоение** весят больше, чем за количество. Достижения не публикуются публично.

### 4.11 Отчёты для родителей
Задач решено, время обучения, изученные и освоенные темы, частые ошибки, предметы, требующие внимания, результаты тестов, динамика. Автогенерация каждые **14 дней** на языке родителя; веб + e-mail. PDF и push — позже. Тексты рекомендаций — шаблонные, проверенные методистом (без свободной генерации ИИ на MVP).

### 4.12 ЕНТ (этап 9)
Отдельный раздел и отдельные таблицы, не смешиваются со школьной программой: подготовка по предметам, тренажёры, пробные экзамены с таймером раз в 14 дней, история, анализ слабых тем. Задания — собственная база; ничего не выдаётся за официальные задания ЕНТ.

### 4.13 Подписки
- **FREE:** теория, формулы, справочник, лёгкие задачи, ограниченные тесты, демо лабораторий.
- **Платный доступ** (15 дней / месяц / год): все три предмета, все уровни, лаборатории, полные тесты, статистика, достижения, отчёты родителю.
- Покупает родитель за конкретного ребёнка (или совершеннолетний пользователь). Отображение срока, статуса, истории платежей. Активация — **только по подтверждённому webhook** провайдера. Неуспешный платёж — понятный статус и повтор. Возвраты — по заявке, обрабатывает админ. Карты не храним.
- Автопродление — отдельный этап, только с отдельным явным согласием.

### 4.14 Двуязычность
Весь UI, уведомления, отчёты — RU/KK. Переключение без потери состояния (локаль в URL, состояние формы/попытки на сервере). Контент хранит языковые версии со статусом перевода; машинный перевод не публикуется без проверки. Подробно — [I18N.md](I18N.md).

### 4.15 Голос (этап 9)
Озвучка теории и решений, выбор голоса. Провайдер-агностичный интерфейс TTS; аудио генерируется заранее и кэшируется. RU — ElevenLabs/альтернативы; KK — отдельная оценка (Yandex SpeechKit, ISSAI KazakhTTS). Основная система не зависит от TTS.

## 5. Ключевые пользовательские сценарии
1. Родитель регистрируется → даёт согласие → создаёт аккаунт ребёнка (логин + пароль или код приглашения) → ребёнок входит.
2. Ученик выбирает класс/предмет → открывает тему → читает теорию → решает лёгкие задачи бесплатно → упирается в платный уровень → видит понятное предложение родителю.
3. Родитель оплачивает 1 месяц → webhook подтверждает → доступ открыт → через 30 дней закрывается, родителю приходит напоминание.
4. Ученик проходит тренажёр на 100 задач → получает «Первые 100 задач» → тема помечается освоенной только после теста.
5. Каждые 14 дней родитель получает отчёт.
6. Контент-менеджер создаёт тему и шаблон задачи → предпросмотр генерации → отправляет на ревью → методист публикует RU, перевод KK проходит отдельную проверку.
7. Админ меняет распределение тем по четвертям для новой учебной программы без участия разработчика.

## 6. MVP
**Входит:** auth и роли, родитель↔ребёнок, согласия; RU/KK; дизайн-система; адаптив; контентное ядро + Studio с ревью; редактор КТП; справочник; движок задач (6 базовых типов + пропуски); тренажёр 100; тесты по теме и разделу; результаты; 3 физические лаборатории + геометрия 2D и 3D (куб/призма/пирамида + сечение); прогресс, XP, серии, 6–8 достижений; кабинет родителя и 14-дневный отчёт; оплата одним провайдером (sandbox → production), возвраты вручную.
**Пилотный контент:** определяет владелец; рекомендация — один класс × 3 предмета × 1–2 четверти, проверенные методистом.
**Не входит:** ЕНТ, EN, TTS, PDF, автопродление, промокоды, мини-игры кроме эталонной, push.

**Критерии готовности MVP** — см. мастер-промт v2: регистрация и выбор языка; ученик видит доступный контент; родитель безопасно привязывает ребёнка; материалы, задачи, тесты сохраняют результаты; лаборатории в едином стиле; подписка открывает/закрывает доступ по серверному статусу; админ управляет контентом, тарифами, пользователями; ключевые сценарии покрыты тестами; документация актуальна.

## 7. Нефункциональные требования
- Mobile-first; LCP < 2.5 с на 4G для страниц темы; лаборатории — lazy-load.
- Доступность WCAG 2.1 AA: контраст, клавиатура, не только цвет.
- Масштаб: архитектура на 50 000 зарегистрированных / 5 000 одновременных без переписывания.
- Доступность сервиса 99.5 % на MVP; RPO ≤ 24 ч (цель 15 мин с WAL), RTO ≤ 4 ч.
- Часовой пояс по умолчанию Asia/Almaty; валюта KZT; формат чисел по локали.

## 8. Метрики продукта
Activation rate, Conversion to paid, ARPPU, MRR, Churn, LTV, CAC, Refund rate, D7/D30 retention, ошибки контента на 1 000 попыток, доля тем с проверенным KK-переводом.

## 9. Открытые вопросы владельцу
1. Стартовая цена годового доступа (17 990 или 19 900 ₸).
2. Пилотный класс и четверти.
3. Выбор облака РК и платёжного провайдера (после переговоров; см. [ARCHITECTURE.md](ARCHITECTURE.md#внешние-сервисы)).
4. Юридические тексты (оферта, политика, согласия, возвраты) — готовит юрист; платформа предоставляет страницы и версионирование согласий.
5. Нужна ли регистрация ученика без родителя для 16+ (рекомендация: нет на MVP).
