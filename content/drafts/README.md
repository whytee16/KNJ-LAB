# Черновики учебных материалов

Здесь лежат **автоматически подготовленные черновики** тем, текстов лабораторий и шаблонов задач.

- Скрипт `pnpm content:import-drafts` загружает их в базу с пометкой `ai_draft`. Существующие записи он не перезаписывает.
- Пока пометка стоит, база не даёт опубликовать материал. Методист читает и исправляет текст в студии, затем нажимает «Проверено учителем» (`mark_content_reviewed`, запись в аудите) и только после этого публикует.
- Место темы в КТП (класс, четверть, раздел) черновики не задают: тему ставит в программу методист в редакторе КТП.
- Казахские тексты здесь не создаются: перевод делает и проверяет носитель языка.

Файлы — JSON: `topic.json` (тема, RU), `lab.json` (тексты лаборатории, RU), `templates.json` (шаблоны задач). Формат задач описан в `packages/task-engine/src/spec.ts`.

Рисунок к задаче задаётся полем `spec.figure` (виды и правила — [ADR-0012](../../docs/adr/0012-task-figures.md)). Подписи на рисунке берутся только из данных условия, неизвестное обозначается «?». Перед загрузкой проверьте все черновики: `pnpm content:check-drafts` (200 наборов параметров на шаблон).
