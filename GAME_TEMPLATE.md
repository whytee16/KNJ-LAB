# GAME / LAB TEMPLATE — KNJ LAB

Все лаборатории (физика, геометрия 2D/3D) и мини-игры строятся на одном шаблоне из `packages/ui/src/game` (импорт `@knj/ui/game`). Разная механика — допустима, разный визуальный стиль — нет.

## 1. Компоненты

| Компонент                    | Назначение                                                                             |
| ---------------------------- | -------------------------------------------------------------------------------------- |
| `GameLayout`                 | каркас: header / workspace / side panel (desktop) или bottom sheet (mobile)            |
| `GameHeader`                 | название, предмет, тема, уровень, выход                                                |
| `GameInstructions`           | цель, шаги, допущения модели (явно)                                                    |
| `GameWorkspace`              | область симуляции (Canvas / SVG / three.js), ресайз, полноэкранный режим               |
| `GameControls`               | параметры: слайдер + числовое поле + единица, кнопки «Запуск / Пауза / Сброс»          |
| `GameReadouts`               | показания приборов и вычисленные величины (с единицами)                                |
| `GameChart`                  | график зависимости (собственный SVG, [ADR-0008](docs/adr/0008-labs-models-in-code.md)) |
| `GameHints`                  | подсказки по запросу                                                                   |
| `GameTasks`                  | вопросы по результату эксперимента: шаблоны задач из `lab_tasks`, проверка на сервере  |
| `GameFeedback`               | результат проверки (статусные токены + иконка + текст)                                 |
| `GameProgress` / `GameScore` | прогресс по вопросам, XP                                                               |
| `GameResults`                | итог, объяснение закономерности, переход к теме/следующему заданию                     |
| `GameNavigation`             | назад к теме, следующая лаборатория                                                    |

## 2. Контракт модели

Каждая лаборатория — пара «чистая модель + представление»:

```ts
// packages/physics/src/ohm.ts (этап 5b; эталон — packages/physics/src/uniform-motion.ts)
export const ohmLab: LabModel<{ U: number; R: number }, { I: number; P: number }> = {
  params: {
    U: { min: 0, max: 24, step: 0.5, unit: 'V' },
    R: { min: 1, max: 100, step: 1, unit: 'Ω' },
  },
  compute: ({ U, R }) => ({ I: U / R, P: (U * U) / R }),
  assumptions: ['labs.ohm.assumption.idealWires', 'labs.ohm.assumption.constantR'],
};
```

- `compute` — детерминированная, покрыта unit-тестами против аналитических значений.
- Динамика (движение, маятник) — фиксированный шаг, время модели отделено от FPS.
- Представление не содержит физики/геометрии — только отрисовку.

## 3. Правила

1. Параметры меняются слайдером **и** вводом числа; значение валидируется по диапазону.
2. Всегда видны единицы СИ.
3. «Сброс» возвращает `default_params`.
4. Mobile: workspace сверху (≥ 50 % высоты), контролы в bottom sheet; жесты — pinch/rotate для 3D.
5. Производительность: 60 fps на desktop, ≥ 30 fps на бюджетном Android; 3D — lazy-load и упрощённые меши, fallback на 2D.
6. RU/KK для всех подписей; формулы не переводятся.
7. Состояние параметров сохраняется в `lab_sessions` (для статистики и «продолжить»).

## 4. Эталон

Реализован на этапе 5a: `packages/physics/src/uniform-motion.ts`, `apps/web/src/features/labs/uniform-motion-lab.tsx`, страница `/[locale]/labs/uniform-motion`. Ждёт утверждения владельцем.

Первая реализованная лаборатория — **Равномерное движение `S = vt`**: параметры `v`, `t`; анимация объекта; график `S(t)`; вопросы по графику. Проверяется на 390 / 768 / 1440 px, RU/KK, клавиатура, тёмная тема → утверждается владельцем как визуальный стандарт.
