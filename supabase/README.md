# supabase/

Local Supabase stack for development (requires Docker). Production runs self-hosted Supabase in a
Kazakhstan cloud — see [ADR-0001](../docs/adr/0001-kz-data-residency.md).

- `config.toml` — local stack configuration (generated by `supabase init`).
- `migrations/` — the only way to change the schema (stage 2+). Every table gets RLS policies.
- `tests/` — pgTAP tests for RLS policies (`supabase test db`).

```bash
pnpm db:start   # start local Postgres, Auth, Storage, Studio
pnpm db:reset   # re-apply migrations from scratch
pnpm db:stop
```
