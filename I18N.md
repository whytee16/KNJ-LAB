# I18N — KNJ LAB

## 1. Языки

- `ru` — русский (основной fallback), `kk` — казахский (кириллица). `en` — этап 9.
- Архитектура на N локалей: добавление языка = новая запись enum `app_locale` + словарь + переводы контента, без изменения кода компонентов.

## 2. Интерфейс

- Библиотека `next-intl`; локаль в URL (`/ru/...`, `/kk/...`) — переключение не теряет состояние: путь сохраняется, состояние попыток/тренажёра хранится на сервере, черновики форм — в URL/локальном состоянии.
- Выбранный язык сохраняется в `profiles.locale` и cookie; язык родительских отчётов и писем — из профиля родителя.
- Словари `packages/i18n/messages/{ru,kk}.json`, ключи по модулям: `common.*`, `auth.*`, `learn.*`, `labs.*` (подписи параметров — `labs.models.<code в camelCase>.*`; тексты лабораторий — в БД), `billing.*`, `errors.*`.
- Типизированные ключи (TS-декларация из `ru.json`); CI-проверка: все ключи `ru` присутствуют в `kk`, нет лишних, нет пустых значений.
- Хардкод текста в компонентах запрещён (ESLint-правило `no-literal-string` для JSX).
- Плюрализация — ICU (`{count, plural, ...}`); даты/числа/валюта — `Intl` по локали (`1 990 ₸`), часовой пояс Asia/Almaty.
- Отсутствующий перевод → значение `ru` + метрика в логах; ключи пользователю не показываются.

## 3. Учебный контент

- Каждая сущность контента имеет `*_translations` со статусом `draft | machine | in_review | approved`.
- Публикуется только `approved`. Если KK-версия не готова — показываем RU с плашкой «Қазақша нұсқасы дайындалуда» (текст из словаря).
- Машинный перевод допускается только как черновик (`machine`) и **никогда** не публикуется без проверки методистом.
- Формулы (LaTeX), обозначения величин, единицы СИ и константы не переводятся — хранятся один раз в нейтральной части сущности.

## 4. Глоссарий терминов

`packages/i18n/glossary.csv`: `term_ru, term_kk, subject, grade_from, source, approved_by`. Источники: действующие учебники РК на казахском языке. Studio подсвечивает термины, отсутствующие в глоссарии. Примеры (для утверждения методистом): дискриминант — дискриминант; сила тока — ток күші; напряжение — кернеу; сопротивление — кедергі; ускорение — үдеу; площадь — аудан; объём — көлем.

## 5. Процесс

1. Автор создаёт RU (или KK) версию → `draft`.
2. Переводчик/автор создаёт вторую версию → `in_review`.
3. Методист-носитель проверяет термины по глоссарию → `approved`.
4. Изменение исходной версии переводит вторую в `in_review` (флаг «устарел»).
