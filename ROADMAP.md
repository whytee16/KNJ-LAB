## План тестирования
| Уровень | Инструмент | Что покрываем |
|---|---|---|
| Unit | Vitest | task-engine (ОДЗ, деление на ноль, размерности, допуски, округление), physics/geometry против аналитики, mastery и достижения, entitlement-границы (Asia/Almaty, переход суток), цены |
| БД | pgTAP | RLS: роль × таблица × операция; родитель не видит чужих детей; ученик не читает `expected`; content_manager не видит ПДн |
| Интеграция | Vitest + локальный Supabase | Server Actions с реальной БД; webhook: подпись, повтор, порядок, неверная сумма, возврат |
| E2E | Playwright (`--trace off` по умолчанию) | ключевые сценарии PRD × {ru, kk} × {390, 768, 1440} |
| Доступность | @axe-core/playwright | все публичные и учебные страницы |
| Визуальные | Playwright screenshots | эталонная лаборатория и базовые компоненты |
| Контент | автопрогон генераторов (N сидов) | каждый шаблон перед публикацией |
| Нагрузка | k6 | 2 000 одновременных в тренажёре, p95 < 300 мс на submitAnswer |
| Безопасность | gitleaks, `pnpm audit`, ручной review, OWASP ASVS L2 чек-лист | этап 8 и каждый релиз |

## Риски
| Риск | Уровень | Митигация |
|---|---|---|
| ПДн несовершеннолетних, локализация | Критический | инфраструктура РК, минимизация, согласия, юр. проверка до запуска |
| Эксплуатация self-hosted Supabase | Высокий | IaC, мониторинг, WAL-G, restore-тесты; план перехода на managed Postgres в РК |
| Ошибки в задачах и решениях | Высокий | автопрогон, ревью методиста, «сообщить об ошибке», журнал |
| Качество казахских терминов | Высокий | глоссарий, статус перевода, ревьюер-носитель |
| Интеграция платежей и ККМ | Высокий | адаптер, sandbox, идемпотентность, reconciliation |
| Объём контента (15 000 задач) | Высокий | шаблоны-генераторы, поэтапная публикация, импорт наработок |
| Лицензии GeoGebra/Desmos | Средний | собственные движки + MIT/LGPL |
| 3D на слабых телефонах | Средний | lazy-load, упрощение, 2D-fallback |
| Низкое удержание | Средний | D7/D30, отчёты родителям, рекомендации |
| Зависимость от одного разработчика | Высокий | AGENTS.md, ADR, CI, документация |
