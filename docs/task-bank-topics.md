# Банк задач: темы на утверждение

Черновик списка тем для пополнения банка задач (физика, алгебра, геометрия). Темы взяты из обычной школьной программы основной школы; **класс указан как ориентир**. Место темы в КТП (четверть, раздел, часы) ставит методист в студии — список его не задаёт.

Всего 85 тем 7–9 классов, из них 9 уже есть на сайте (по ним добавятся задачи до 15), рисунок нужен в 55. По каждой теме — 15 шаблонов задач: лёгкий 4, средний 4, достаточный 4, сложный 3. Темы 10–11 классов — следующим этапом.

Как ответить: вычеркните ненужное, допишите недостающее и назовите первые 5–8 тем по кодам (например, «Ф7.4, Ф7.9, А8.2, Г8.3»).
