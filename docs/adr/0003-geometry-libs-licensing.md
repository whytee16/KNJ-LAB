# ADR-0003: Библиотеки геометрии и графиков с учётом лицензий

Статус: предложено (2026-11-21)

## Контекст
GeoGebra бесплатна для некоммерческого использования; коммерческое встраивание требует лицензии. Desmos API требует соглашения/ключа для коммерческого использования. Условия нужно подтверждать у правообладателей на дату внедрения.

## Решение
- 2D: собственный SVG-движок (`packages/geometry` — вычисления, `packages/ui/game` — отрисовка) + JSXGraph (LGPL/MIT dual) для построений.
- 3D: three.js + @react-three/fiber + drei (MIT).
- Графики функций и данных: собственный SVG + Recharts (MIT).
- Формулы: KaTeX, MathLive, Compute Engine (MIT).
- GeoGebra/Desmos — только после получения письменной коммерческой лицензии, через отдельный ADR.

## Последствия
+ Нет лицензионных рисков, полный контроль UX и дизайна.
− Больше собственной разработки для геометрических построений.
