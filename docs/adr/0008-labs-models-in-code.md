# ADR-0008: Лаборатории — модели в коде, тексты и вопросы в БД

Статус: принято (2026-11-22)

## Контекст

Лаборатория — это расчётная модель (физика, геометрия), её отрисовка и учебная обвязка: цель, шаги, подсказки, привязка к темам, вопросы по результату эксперимента. Модель должна быть проверяемой unit-тестами и не меняться без ревью кода. Обвязку пишут методисты, и она нужна на двух языках.

## Решение

- Модели — чистые функции в `packages/physics` (позже `packages/geometry`) по контракту `LabModel` из [GAME_TEMPLATE.md](../../GAME_TEMPLATE.md): диапазоны параметров, `compute`, допущения. Время модели идёт фиксированным шагом и не зависит от частоты кадров.
- Отрисовка — `packages/ui/game` и представление лаборатории в `apps/web/src/features/labs`. Каждая лаборатория загружается отдельным чанком.
- Строка в `labs` появляется только миграцией вместе с моделью (`labs.code` = код модели). Студия не создаёт и не удаляет лаборатории. Она правит тексты RU/KK, параметры по умолчанию (сервер проверяет их по диапазонам модели), флаг «бесплатное демо», класс, темы и вопросы. Публикует методист.
- Вопросы — опубликованные шаблоны задач движка этапа 4, привязанные через `lab_tasks`. Ответы проверяются на сервере (`attempts.kind = 'lab'`), ключи в клиент не уходят.
- Доступ: демо-лаборатория работает у всех, вопросы и сохранение доступны ученикам. Остальные лаборатории требуют активный пропуск. Сервер не отдаёт симуляцию без доступа, а триггер БД не даёт сохранить сессию или попытку без пропуска даже под service role.
- Графики — собственный SVG (`GameChart`), без Recharts. Этого достаточно для графиков зависимостей, нет зависимости, и стиль полностью задаётся токенами. ADR-0003 такой вариант допускает.

## Последствия

- Корректность физики проверяется тестами пакета, а не ревью контента.
- Добавить лабораторию — значит изменить код (модель, представление, миграция реестра). Это осознанное ограничение.
- Код симуляции платной лаборатории — публичный JS-чанк. Платным считается доступ к странице, вопросам, сохранению и статистике, а не сама формула.
