# ADR-0001: Хранение и обработка ПДн в Казахстане

Статус: принято (2026-11-21) · Решение владельца

## Контекст
Пользователи — несовершеннолетние граждане РК. Закон РК «О персональных данных и их защите» требует хранения ПДн в базе на территории РК и согласия законного представителя. Supabase Cloud и Vercel размещены за рубежом. Аудит оценил зарубежное размещение основной БД как критический риск.

## Решение
- PostgreSQL, Auth (GoTrue), Storage и бэкапы — self-hosted Supabase в облаке РК (кандидаты: PS Cloud, QazCloud, Hoster.kz).
- Next.js (серверные функции обрабатывают ПДн) и worker — там же.
- Vercel — только для превью без реальных данных.
- Код остаётся совместимым с Supabase Cloud (стандартный `@supabase/ssr`, миграции CLI).

## Последствия
+ Соответствие требованиям локализации; контроль над данными.
− Эксплуатация на нас: обновления, мониторинг, бэкапы, restore-тесты.
− Нет «магии» Vercel (edge, ISR-кэш) — используем self-hosted Next.js в Docker.

## Альтернативы
Supabase Cloud на старте с переездом позже — отклонено (двойная работа, риск при приёме реальных детей). Свой Postgres + собственная auth — больше кода и рисков безопасности.
