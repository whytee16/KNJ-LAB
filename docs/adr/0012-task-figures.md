# ADR-0012: Рисунки в задачах — декларативные, из параметров

Статус: принято (2026-11-26)

## Контекст

Для банка задач по геометрии и физике нужны рисунки: треугольники, окружности, графики, силы, рычаги, сосуды, электрические схемы. Задачи генерируются из шаблонов со случайными параметрами, поэтому рисунок должен строиться по тем же числам, что и условие. Правильный ответ не должен попадать к ученику — ни в текст, ни в рисунок.

## Решение

- В `spec` шаблона есть необязательное поле `figure` (`packages/task-engine/src/figure.ts`, схема `figureSchema`). Это описание данными, без кода:
  - **виды:** `right_triangle`, `triangle`, `circle`, `quad`, `plot`, `forces`, `lever`, `vessel`, `circuit`, `scale` (линейка, мензурка, термометр, динамометр);
  - **числа** — выражения mathjs от параметров;
  - **подписи** — текст с `{{param}}`, неизвестная величина обозначается «?».
- При выдаче задачи сервер вычисляет рисунок для выпавших параметров и раскладывает его в простые примитивы: линии, многоугольники, дуги, стрелки, подписи (`buildFigure`). Примитивы кладутся в `prompt.figure`; браузер только рисует их в SVG (`apps/web/src/features/practice/figure.tsx`).
- Пропорции соответствуют числам: треугольник 3–4–5 действительно прямоугольный, длины сторон совпадают с условием. Невозможная фигура — нарушено неравенство треугольника, тело не помещается в сосуде — даёт ошибку генерации. Поэтому шаблон с такими параметрами не проходит проверку (`validateTemplate`, `pnpm content:check-drafts` — 200 наборов на шаблон).
- Графики функций разбиваются на асимптотах и обрезаются по границам осей.
- Форма студии рисунки не редактирует. При правке шаблона его рисунок сохраняется. Рисунки приходят из черновиков (JSON).
- Миграция не нужна: `spec` уже хранится в jsonb.

## Последствия

- Новый вид рисунка — функция раскладки в `figure.ts` с тестом; отрисовщик не меняется.
- Автор шаблона отвечает за то, чтобы подписи не раскрывали ответ. Это проверяется на ревью учителем.
- Стереометрия (3D-фигуры) пока не поддерживается.

## Дополнение: производные величины и импорт банка (2026-11-26)

- `spec.derived` — значения, вычисленные из параметров по порядку: данные задачи, собранные из «удобных» чисел, и промежуточные результаты для пошагового решения. Они доступны в ограничениях, ответе, рисунке и текстах. Решение хранится на сервере и показывается только после ответа.
- `task_templates.draft_key` — ключ черновика (`<папка>#<номер>`). Импортёр добавляет только новые шаблоны, поэтому повторный запуск ничего не дублирует. Задачи к существующей теме лежат в `content/drafts/bank/<предмет>/<папка>/` с файлом `bank.json` `{"topic": "<slug>"}`.
