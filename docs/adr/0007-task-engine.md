# ADR-0007: Движок задач и проверка ответов

Статус: принято (2026-11-22)

## Контекст

Нужны тысячи вариантов задач (генерация из шаблонов), проверка семи типов ответов, включая формулы, и защита правильных ответов от учеников.

## Решение

- Чистый пакет `packages/task-engine` без React и БД: генерация по seed (mulberry32), проверяющие функции, валидация шаблона на 50 вариантах. Тот же код работает в студии (предпросмотр) и на сервере (выдача и проверка).
- Выражения шаблонов — mathjs в песочнице (Apache-2.0). Формулы учеников — LaTeX из MathLive (MIT), разбор @cortex-js/compute-engine (MIT) 0.173 — последняя версия, совместимая с Node 22. Эквивалентность — сравнение в 20 случайных точках диапазона с пропуском точек вне ОДЗ; при недостатке точек ответ «не удалось проверить», а не «неверно».
- Экземпляр задачи хранит условие (для ученика) и ключ (только для сервера) раздельно; версия шаблона фиксируется в экземпляре.

## Последствия

- Задачи воспроизводимы (seed), история не меняется при правке шаблонов.
- Проверка формул вероятностная: для выражений, совпадающих в выбранных точках, но различных в других, возможна ошибка; диапазон проверки задаёт автор.
- Обновление compute-engine выше 0.173 требует Node 26.
