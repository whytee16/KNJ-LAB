# Реестр лабораторий по физике (черновик)

> **Черновик, требует проверки учителем.** Список составлен автоматически как отправная точка. Классы и четверти не указаны: распределение по КТП задаёт методист. Источник данных — `content/drafts/physics/labs-catalogue.json`.

Всего тем: 64. Готово: 12. Можно собрать сценарием на существующих решателях: 5. Остальным нужен новый решатель или отдельная модель.

Состояния: **готово** — лаборатория есть; **конструктор** — решатель есть, нужен только сценарий (и иногда раскладка сцены); **нужен решатель** — новый блок движка.
