# Живой демо-сайт на своём компьютере

Сайт запускается целиком на вашем компьютере: база, вход, тренажёр, тесты, лаборатории, студия. Данные выдуманные и никуда не уходят. Подходит для проверки, а не для учеников.

## 1. Что установить (один раз)

1. **Docker Desktop** — https://www.docker.com/products/docker-desktop/ (Windows: при установке оставьте включённым WSL 2). Запустите и дождитесь зелёного статуса «Engine running».
2. **Node.js 22 LTS** — https://nodejs.org/ (кнопка LTS).
3. **Git** — https://git-scm.com/downloads.
4. Откройте терминал (Windows — «PowerShell», macOS — «Терминал») и включите pnpm:

```bash
corepack enable
```

Компьютеру нужно не меньше 8 ГБ оперативной памяти и около 10 ГБ свободного места.

## 2. Скачать проект (один раз)

```bash
git clone https://github.com/whytee16/KNJ-LAB.git
```

```bash
cd KNJ-LAB
```

```bash
git checkout claude/clever-lamport-ukylh6
```

```bash
pnpm install
```

## 3. Запуск

```bash
pnpm demo
```

Первый запуск — 10–15 минут: Docker скачивает базу данных. Когда в терминале появится «Готово», откройте **http://localhost:3000**.

`pnpm demo` каждый раз создаёт **чистую** базу. Чтобы продолжить со своими данными (например, после перезагрузки компьютера), используйте:

```bash
pnpm demo:start
```

Остановить сайт — `Ctrl+C` в терминале. Освободить память — `pnpm db:stop`.

## 4. Аккаунты

Логины печатаются в конце запуска и сохраняются в файл `DEMO-ACCOUNTS.md` в папке проекта.

| Роль                             | Логин                 | Пароль        |
| -------------------------------- | --------------------- | ------------- |
| Ученик (9 класс, пропуск на год) | `demo.uchenik`        | `Demo2026knj` |
| Методист (студия)                | `metodist@demo.local` | `Demo2026knj` |
| Родитель ученика                 | `roditel@demo.local`  | `Demo2026knj` |

Методисту при первом входе нужно подключить приложение-аутентификатор (Google Authenticator, Microsoft Authenticator и т. п.): так защищена студия.

## 5. Порядок проверки

Весь учебный контент подготовлен автоматически и **не виден ученику, пока его не проверит учитель**. Поэтому сначала методист, потом ученик.

1. **Методист** → «Студия»:
   - «Лаборатории» → откройте лабораторию, прочитайте тексты и вопросы → «Проверено учителем: тексты и все вопросы» → «Опубликовать лабораторию с вопросами». Галочка «Бесплатное демо» открывает лабораторию и без входа;
   - «Темы» → откройте тему → «Проверено учителем: текст и все задачи» → «Опубликовать тему с задачами». Чтобы тема появилась в каталоге «Темы», поставьте её в учебную программу («Учебная программа»);
   - тест-экзамен по теме можно собрать в «Студия → Тесты».
2. **Ученик** → «Лаборатории» (двигайте параметры, «Запуск», 3D/2D, схема сил, вопросы), страницы тем (тренажёр 4 уровней), «Тесты», кабинет.
3. **Родитель** → статистика ребёнка.

## 6. Если что-то не так

- «Docker не запущен» — откройте Docker Desktop и подождите зелёного статуса.
- Порт 3000 занят — закройте другую программу или перезагрузите компьютер.
- Начать с нуля — снова `pnpm demo`.
