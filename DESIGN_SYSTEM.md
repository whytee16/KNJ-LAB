# DESIGN SYSTEM — KNJ LAB

Версия 0.1. Стиль: минимализм, премиальный SaaS, серьёзная образовательная эстетика для 13–17 лет. Визуальная основа из концепции: **кремовый фон · тёмная типографика · оранжевый акцент**. Без мультяшности.

Токены живут в `packages/ui/tokens` (CSS-переменные + Tailwind theme). Хардкод цветов/отступов в компонентах запрещён.

Краткая выжимка для ИИ-агентов в формате awesome-design-md — [DESIGN.md](DESIGN.md) (утверждённый вариант A, ноябрь 2026). При расхождении прав этот документ.

Все текстовые цвета проверены на контраст WCAG AA ≥ 4.5:1 на `--bg`, `--surface-muted` и 10 %-тонировках (бейджи); проверка выполняется автоматически axe в e2e-тестах. Исходные оттенки из концепции (`#E8660C` и др.) не проходили 4.5:1 и были затемнены.

Статусные цвета (success/danger/warning/info) одинаковы во всех модулях, включая лаборатории. Статус всегда дублируется иконкой и текстом.

## 2. Типографика

- Шрифт: **Inter Variable** (кириллица + казахские буквы ә ғ қ ң ө ұ ү һ і), самохостинг через `@fontsource-variable/inter` — без запросов к внешним CDN.
- Шкала (mobile → desktop): `display 32/48`, `h1 28/36`, `h2 22/28` (классы `type-display`, `type-h1`, `type-h2`, жирность 700, трекинг −0.02em), `h3 18/22`, `body 16`, `small 14`, `caption 12`. Межстрочный 1.5 для текста, 1.2 для заголовков.
- Формулы KaTeX наследуют цвет `--text`, размер 1.1em; блочные формулы скроллятся горизонтально на узких экранах.

## 3. Пространство и форма

- Отступы: шкала 4 px (`4, 8, 12, 16, 24, 32, 48, 64`).
- Сетка: 4 колонки (mobile, поля 16), 8 (tablet, 24), 12 (desktop, max-width 1200).
- Брейкпоинты: `sm 640`, `md 768`, `lg 1024`, `xl 1280`.
- Радиусы: `sm 6`, `md 10`, `lg 16`, `full`.
- Тени: `sm` (карточки, одна лёгкая тень `0 1px 2px`), `md` (поповеры); разделение — тонкими границами; в тёмной теме — только границы.
- Сенсорные цели ≥ 44×44 px.

## 4. Движение

150–250 мс, `ease-out`; уважать `prefers-reduced-motion` (анимации симуляций — по кнопке «Запуск», а не автоматически).

## 5. Компоненты (packages/ui)

Базовые (на shadcn/ui + Radix): Button (primary/secondary/ghost/danger, sizes), Input, NumberInput с единицами, FormulaInput (MathLive), Select, Tabs, Dialog, Sheet (мобильные панели), Toast, Tooltip, Badge, Card, Progress, Skeleton, EmptyState, LanguageSwitcher, PaywallCard, DifficultyBadge, Formula (KaTeX), StatTile, Chart-обёртки Recharts.
Учебные: TopicStepper (8 шагов), TaskCard, AnswerFeedback, SolutionSteps, HintPanel, TestTimer, ResultSummary, AchievementBadge, StreakIndicator.
Лабораторные — см. [GAME_TEMPLATE.md](GAME_TEMPLATE.md).

Каждый компонент: состояния default/hover/focus-visible/active/disabled/loading/error; RU и KK длина текстов (KK ≈ +20–30 %); тёмная тема.

## 6. Доступность

WCAG 2.1 AA: контраст, `focus-visible` кольцо `--accent` 2 px, клавиатура для всех контролов лабораторий (слайдеры — стрелки, PgUp/PgDn), `aria-live` для результата проверки, `lang` атрибут по локали.

## 7. Тон

Обращение на «ты» к ученику, на «вы» к родителю. Короткие, точные формулировки; без восклицательных знаков в ошибках. Тексты — в i18n-словарях.
